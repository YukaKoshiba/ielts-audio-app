# English Vocabulary Audio App

IELTS vocabulary learning app for audio-based study.

## Overview

## Overview

This project started as a personal tool for studying English vocabulary for the IELTS exam.

While raising a child, I found it difficult to set aside dedicated time for studying. However, I realized that although my hands were often occupied, I still had time when my ears were free.

This led me to explore audio-based learning as a way to study English vocabulary while doing other activities.

The vocabulary data used in this application comes from two sources:

* Vocabulary from a TOEIC vocabulary book
* English words that I encountered in daily life and did not know, which I had previously collected in an Excel file

The initial goal is to turn these personally collected vocabulary lists into an audio learning application that I can actually use in my daily life.

Rather than starting with a complex system, I am first focusing on building a simple application that solves my own learning challenge.

### Features

- 📖 覚える (Learn mode) — word / meaning / example, with 英→日 and 日→英 audio playback
- 🔁 復習 (Review mode) — Recall → Answer → ◎ / △ / × self-rating
- 🎧 音声学習 (Audio-only mode) — hands-free playback of all 10 words in sequence
- ✏️ クイズ (Quiz) — 英→日 / 日→英 4-choice quiz

## How to use

Open `index.html` on your iPhone or iPad (via a static host — see
[Development](#development)) and add it to your Home Screen.
