# IELTS Audio App

IELTS vocabulary learning app for audio-based study.

## Day 1

Vocabulary: 1781–1790

### Features

- Learn mode
- Review mode
- Audio learning mode
- English → Japanese
- Japanese → English
- Recall → Answer
- ◎ / △ / × learning evaluation
- Quiz

## How to use

Open the app on your iPhone or iPad and add it to your Home Screen.
